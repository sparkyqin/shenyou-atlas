# 神游 · 中国神仙与庙宇图鉴

**在线访问：[神游图鉴](https://sparkyqin.github.io/shenyou-atlas/)**

GitHub Pages 已启用。更新 `main` 分支中的网站文件后，GitHub Actions 会先检查页面和图片，再自动发布 `dist/`。也可在 Actions 页面手动运行发布工作流。

面向旅行看庙的中文互动图鉴，以神明人物为中心，串联故事、职掌、神像辨认、相关神祇与供奉庙宇。

## 当前内容

- 69 个神明条目，均有三段故事与配图
- 82 条带语境说明的人物关系
- 40 处代表性庙宇与圣地，覆盖 18 个地区
- 26 类殿名辨认线索、6 篇入门读本、4 部古籍阅读入口
- 74 项图像及文献配图记录、153 条文字资料来源

## 本地运行

不需要安装前端依赖或构建。

```sh
python3 -m http.server 8080 --directory dist
```

在浏览器打开 http://localhost:8080 。静态托管时，将 `dist/` 设为发布目录。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| `dist/index.html` | 页面骨架和导航 |
| `dist/app.js` | 图鉴、关系图谱、搜索筛选、故事与看庙导览 |
| `dist/styles.css` | 视觉设计与响应式布局 |
| `dist/data.js` | 神明、关系、庙宇、故事、书目与图像元数据 |
| `dist/assets/` | 本地图片资源 |
| `docs/image-credits.csv` | 图片来源、作者、授权与处理说明 |
| `docs/sources.csv` | 文字资料来源索引 |
| `scripts/check-render.cjs` | 全站路由渲染与本地图片完整性检查 |

## 内容维护

`dist/data.js` 将数据赋给 `window.ATLAS_DATA`。人物 ID 是关联关系、庙宇和殿名条目的键。

人物故事使用 `hook`、`storyTitle`、`storyParagraphs`、`storySources`。新增或修改资料时，同时维护 `sources` 和人物引用。图像元数据保留 `sourceUrl`、`credit`、`license`、`licenseUrl`、`changes` 和必要的 `note`。

```sh
node --check dist/app.js
node scripts/check-render.cjs
```

## 阅读与图像说明

中国神祇信仰跨越不同时代、地区和宗教传统。这里按具体文献和语境记录关系，不将所有传统归并为一套唯一等级表。庙宇目录为代表性精选，现场供奉与陈设应结合当地题牌、碑记和寺观说明核对。

图像包括古籍刻图、公版馆藏图像、按授权使用的实拍以及明确标注的文献排印。库官配图为古籍原文的现代排印，部分组合神或职掌类条目采用注明具体对象的相关图像。太岁旧籍图像不代表六十甲子每一尊的固定造型。

第三方图像和资料遵循各自授权。代码、原创整理文本与第三方素材的权利分别处理，本仓库未统一授予开源许可；请保留原作者、出处、授权和修改说明。
