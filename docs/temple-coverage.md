# 收录范围审视（2026-11-24）

## 当前结论

资料库尚不全面。当前 69 个“神明条目”含单个人物、组合尊神和神职类别，82 条关系是已有资料支持的选取，不构成全部神祇或关系的穷尽目录。庙宇导览收录 41 处，分布于 18 个地区，部分条目为宫观群或山岳寺院群，不能视为逐座寺庙的全国统计。

上一轮从人物条目反向选取旅行目的地，没有先建立全国重要寺观的对照名录，因此法门寺等重要寺院遗漏。这是编录方法的缺口，不能仅用寺庙数量众多来解释。当前没有全国覆盖率，也不能据此推断某省或某座寺院已完整收录。

## 本轮实质补充

新增法门寺，关联释迦牟尼佛与佛指舍利信仰，补充 1987 年地宫考古、唐代迎奉与供养、博物馆及碑刻阅读线索。资料分别来自宝鸡市文物局和新华社报道。当前关联不等于寺内现存所有佛、菩萨与护法的完整清单。

## 扩充所需的可核验标准

1. 分别建立佛寺、道观、民间庙宇、祠庙与石窟等范围的候选基线，并保留名单来源与版本；避免把“寺院群”和单寺混成全国总数。
2. 每个候选记录收录状态：未核验、资料核验、导览完成、图像与逐殿核验；已有来源只证明具体事实，不自动代表全条目完整。
3. 每座庙分别记录历史信仰对象、当前主祀、配祀与文物图像，并说明具体证据。关联一位神明不能等同完整供奉名单。
4. 分开公布候选基线覆盖、地区分布、人物关联、图片出处与内容深度；只有分母明确的基线才能给覆盖率。
